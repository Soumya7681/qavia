# Vision

> Upload a requirement, API specification, or code repository, and AI automatically generates, executes, and maintains all the tests.

Instead of replacing QA engineers, it acts as an AI QA Engineer.

# AI Agents

Instead of one AI model, use specialized agents.

## Requirement Agent

Reads business requirements.

Output

* Features
* Acceptance Criteria
* Business Rules

---

## Test Design Agent

Creates

* Functional tests
* Edge cases
* Negative scenarios

---

## Code Agent

Reads

* APIs
* Controllers
* Services
* Database

Detects uncovered code paths.

---

## UI Agent

Reads

* React
* Angular
* Vue
* HTML

Finds buttons, forms, workflows, and generates Playwright or Cypress tests.

---

## API Agent

Reads

* Swagger
* OpenAPI
* Postman

Creates API tests.

---

## Execution Agent

Runs all tests.

Collects

* Logs
* Screenshots
* Videos
* Reports

---

## Analysis Agent

Analyzes failures.

Finds

* Root cause
* Related commits
* Suggested fixes
